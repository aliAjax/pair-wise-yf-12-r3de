# 油站网点与便利店批次管理

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、localStorage
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原油站网点维护的最小闭环上，新增便利店**按保质期分批**的库存柜台，数据全部保存在浏览器 localStorage。

## 页面

- **油站网点**：原网点功能（位置、营业状态、库存摘要、状态流转、区域筛选、图表）保持可用，数据仍存于 `hxwlfront-21-station-map`。
- **便利店批次柜台**：先选油站，再进行批次登记、折扣贴签、销售、撤销、调拨，并查看当日销量。

## 业务规则（对应业务文件）

| 业务文件 | 职责 |
| --- | --- |
| `src/business/catalog.ts` | 商品规则：条码、名称、进价、售价、保质期；折扣价/售价不得低于进价 |
| `src/business/ledger.ts` | 批次台账：批次登记、FEFO 扣减、过期自动下架、折扣贴签、撤销退回原批次、整批调拨与货位校验、当日销量统计 |
| `src/views/StationsView.vue` | 油站页面：原网点功能 |

关键规则：

1. **分批登记**：同一商品不同保质期各是一个批次（条码、名称、进价、数量、到期日），每批占 1 个货位，库存不再合并。
2. **FEFO 销售**：结算从最早到期的在架批次扣减，可先预览扣减方案；贴签批次按折扣价成交。
3. **过期自动下架**：到期日早于今天的批次不参与销售与调拨，台账中标记"已过期下架"，跨天自动刷新。
4. **折扣底价**：贴签价低于进价直接拒绝（售价同样不得低于进价）。
5. **撤销销售**：数量退回销售时的**原批次**，即使该批次已过期或已调拨到其他站；找不到台账则按快照重建。
6. **整批调拨**：只有未拆零、未过期的批次可调拨；接收站必须空得出货位，否则整笔取消、两边库存原样保留。
7. **页面查询**：批次按状态/关键字查询，可查看当前折扣批次和当日销量（笔数、件数、金额、毛利、撤销数）。

localStorage 键：

- `hxwlfront-21-station-map`（油站网点，沿用旧键）
- `hxwlfront-21-product-catalog`（商品规则）
- `hxwlfront-21-batch-ledger`（批次、销售、调拨、货位）
